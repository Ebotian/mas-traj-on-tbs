# 基于组合采样的电价规则构建与实验方案

## 研究结论与范围

本课题以储能设备已经存在为前提，固定设备模型、并网接口与执行策略，研究电价规则如何由已知构件解析组合，并通过组合采样形成公平比较预测训练损失的实验面板。主采样对象是电价的计量、计价、结算和信息揭示结构，以及这些结构的参数；不将设备容量优化、设备非线性和跨行业任务扩张为本轮主问题。

建议的核心路线是：有类型的电价规则表达 → 合法且有界的组合空间 → 明确目标分布的采样 → 计费语义核对 → 决策行为覆盖 → 候选损失的配对实验 → 独立确认。此前的LP、QP、混合整数、随机及动态规则族继续作为数学性质标签和求解适用边界，不再作为需要同时扩建的六个世界库。

调查表明，电价规则建模已有可以借鉴的工程基础。SAM的官方说明覆盖电量、需量、固定及最低账单等结构，并区分不同净额计量与结算方式，也明确承认其表达范围有限。它支持建立已有规则目录，但不能证明某份现实合同已经完整录入。[^1] McKenna的储能电价研究则直接比较不同费率结构诱导的储能行为，提供了“固定设备、改变电价结构”的相关先例。[^2]

本轮新增的重要文献是2026年8月上线的研究：按一个月内最高若干个日峰值的平均值分档计费。作者采用MILP表达，并明确区分完美未来信息下界与可实施MPC。这个例子说明，电价不是只有逐时单价；计费历史与离散档位也会改变预测—调度传导。[^3]

采样方面，受约束组合覆盖、近均匀SAT采样和加权模型采样均有可借鉴工作。它们解决不同问题：覆盖数组保证所声明的有限交互出现；近均匀采样控制分布；加权采样服务明确目标分布。没有一种自动保证电价行为全面覆盖。[^4][^5][^6]

本文提出的规则目录、参数范围、实验卡和验收条件是研究设计建议，不是已经验证的现场费率或算法效果。检索核查截至2026年9月14日。本轮实际执行了一个小型离散组合枚举与覆盖构造，结果见第9节；未运行储能闭环或候选训练，也未审查最新仓库源码。

## 1．研究问题与明确假设

### 1.1 三项研究问题

Q1：由已知电价构件采样得到的组合，能否保持清晰、可独立核对的计费语义？

Q2：在相同生成和求解预算下，哪些采样方法更有效地覆盖规则交互、计费边界与决策变化？

Q3：在这些电价组合下，候选损失保留了哪些决策信息，何时改善真实账单，何时因计价顺序、历史状态或跳变而失效？

Q1和Q2是Q3证据可信的条件，但不要求逐个算法串行实现。不同电价规则和候选可以并行推导；所有比较必须引用共同冻结的世界和评估口径。

### 1.2 预测目标不能与规则知识混淆

设电价规则为τ，预测输出为z。分别定义两个实验轨道：

| 轨道 | 已知信息 | 预测对象 | 主要目的 |
|---|---|---|---|
| P-load，主轨道建议 | 已公布电价表、计费机制、当前计费历史 | 未来净负荷 | 隔离电价结构怎样诱导负荷预测损失 |
| P-price，独立扩展 | 计价机制、已公布价格前缀和公布时间 | 尚未公布的浮动价格；负荷先固定为已知 | 隔离价格预测误差的传导 |

两者的联合预测属于第三个独立变体，不把其收益与单目标预测直接混排。已经公布的分时表不应被故意隐藏后称为现实预测难题；有意隐藏只能标为专门的信息实验。

固定T₀指固定调度算法、规划时域、择优规则与信息接口，并允许它读取不同τ；不意味着所有电价组合使用相同动作。若某损失只能与另一调度器一起工作，应登记为联合变体。

## 2．电价应表示为带状态的计费程序

### 2.1 储能与净交换功率

设时间步长Δt以小时计，储能能量e为kWh，功率为kW。所有候选共享

\[
e_{t+1}=e_t+\Delta t(\eta_c p_t^c-p_t^d/\eta_d),
\qquad g_t=y_t+p_t^c-p_t^d,
\]

以及固定的容量、功率、初末状态、进出口和充放电互斥条件。设备与执行约束不作为电价原子反复采样。若使用连续松弛，须有适用条件证据，或单列为共同松弛轨道。

特别地，负价格下不能未经证明地假定最优解自然避免同时充放电。物理互斥若为固定契约的一部分，所有候选和基准均需遵守。将设备损耗或退化成本D(u)固定且单独记账，避免将设备费用误称为电价。

### 2.2 电价的输入、状态与输出

建议写为

\[
(b_{t+1},c_t)=K_\tau(b_t,g_t,k_t,p_t),
\qquad B_\tau=\sum_t c_t+\operatorname{Close}_\tau(b_T).
\]

其中b为计费状态，k为日历与窗口索引，p为按信息协议可用的价格，Close为结算周期结束时的清算。c可以只记已确定的增量，而把某些费用留到Close；不得重复计费。

b可包括累计电量、当前需量窗口累加量、当月峰值、已完成各日的top-N峰值、当前日峰值、历史需量基准及结转余额。并非所有规则都需要全部字段；状态结构由已启用模块决定。

这样的表述使月度费用也能在5分钟控制系统中被明确处理。它不把月费除以天数伪装成日费，也不在每天重置仍应保留的历史状态。

### 2.3 四类有类型的组合操作

| 操作 | 输入与输出 | 例子 |
|---|---|---|
| 计量 Meter | 功率轨迹 → kWh、窗口平均kW、日峰值 | 5分钟功率聚合为15分钟需量 |
| 计价 Rate | 计量量及价格参数 → 金额 | 分时电量价、阶梯电量价、分档需量费 |
| 合并 Add | 不重叠或明确附加的金额项 → 小计 | 电量费＋需量费＋固定费 |
| 结算 Settle | 小计及历史余额 → 账单与新余额 | 最低账单、净额抵扣、周期清算 |

规则连接必须匹配单位、计量对象、窗口和时间顺序。范畴论组合控制工作提供了构件与结构化组合的理论参照；本课题可借鉴类型化连接，不需要先实现一个完整范畴论平台。[^7]

## 3．组合顺序是必须采样和检查的因素

以下为本文的直接构造与手算，不是现实费率声明。

### 3.1 逐时购售与整段净额不等价

两个一小时时段净交换为g=(1,−1) kW，买价1、卖价0.2。

逐时购售结算：1×1−0.2×1=0.8。

整段净电量为0，按净额计价得0。

所以“先取正负部再聚合”与“先聚合再取正负部”不是同一规则。只有当相应条件成立时才可能相等，不能因都叫net metering/net billing就合并。

### 3.2 阶梯计费窗口不同会改变账单

令T(Q)=min(Q,1)+2(Q−1)₊，Q≥0。两个窗口各用1 kWh，分别计价为T(1)+T(1)=2；合并为同一窗口后T(2)=3。

因此全月阶梯、各分时时段独立阶梯和逐日阶梯须有不同声明。阶梯价若已给出全部边际单价，不得再叠加另一份完整基础电量价；只有声明为增量附加价时才可相加。

### 3.3 最低账单的作用范围不同

固定费2、其他费用4、最低账单5。

最低值覆盖全部费用：max(5,2+4)=6。

最低值只覆盖其他费用：2+max(5,4)=7。

固定费仅在纯加法、没有相关门槛或结算交互时，对动作优化是常数项。加入最低账单后，它可能改变是否跨过门槛，不能无条件从优化问题删除。

### 3.4 计量周期不同于控制周期

三个5分钟功率为(9,0,0) kW。若合同以这一固定15分钟窗口平均功率计需量，则为3 kW，而非9 kW。滚动15分钟窗口与不重叠窗口也不等价，需分别声明边界对齐。

这些反例应进入自动核对集，防止组合采样仅增加语法变化而没有保留数学含义。

## 4．已知电价构件目录与覆盖边界

下面是面向研究的候选目录。分类参考官方计费文档与相关论文，但公式是本课题需要逐条确认的合成语义；不能把整张表解释成某国家现行合同集合。真实费率复验必须附合同出处、生效期与适用客户类型。

| 编号 | 电价构件 | 需要参数化的内容 | 必须保留的语义 |
|---|---|---|---|
| E0 | 固定电量单价 | 买价、卖价、货币尺度 | 收购和购买的符号 |
| E1 | 分时、季节、工作日价表 | 时段、日历映射、价差 | 公布时间、边界对齐 |
| E2 | 浮动价格及附加价 | 已知前缀、未来随机部分、加价方式 | 不把全部未来价格默认已知 |
| E3 | 递增/递减边际阶梯 | 阈值、边际价格、重置周期 | 增量阶梯与整段重定价不同 |
| X0 | 逐时进出口分别计价 | 购售差、出口补偿 | 零补偿不等于物理禁止出口 |
| X1 | 按窗口净额计量 | 净额窗口、分时归属、负余额处理 | 不跨不相容价格窗口随意抵扣 |
| D0 | 最大需量费 | 计量窗口、收费系数、范围 | 最大平均功率，非瞬时峰值 |
| D1 | 历史需量基准/ratchet | 历史窗、比例、当前历史值 | 基准必须来自过去或声明初态 |
| D2 | top-N日峰值平均后分档 | N、日峰定义、分档阈值和费用 | 保存足够历史；跳变边界归属 |
| F0 | 固定费 | 金额、周期 | 可作为不影响动作的负控制 |
| F1 | 最低账单 | 金额、作用范围、净收益处理 | max的位置 |
| S0 | 结转与清算 | 电量/金额余额、失效和结算规则 | 跨周期状态与出口信用顺序 |

SAM可作为E、X、D、F及部分S结构的工程参考，但其说明明确提醒不同语境中的净额术语可能不同。[^1] D2有直接的近期储能论文依据；其真实研究情境不自动代表其他市场。[^3]

本轮主支持集建议先声明为：E0/E1、E3的明确边际阶梯、X0、一个明确的X1简化版、D0/D1/D2、F0/F1。E2与S0作为有独立信息/状态契约的扩展。这里的“主支持集”是共同实验范围，不是候选算法优先级，也不要求所有研究工作串行开展。

对未支持的组合记录“语义尚未定义”，不要判为现实中不存在。例如净额计量叠加阶梯收费有多种合法设计，不能因为当前生成器未编码就统一排除为非法。

## 5．解析表达与可核对性质

### 5.1 电量费用

逐时购售费用为

\[
B_E(g)=\Delta t\sum_t\big[p_t^+(g_t)_+-p_t^-(-g_t)_+\big].
\]

在p⁺≥p⁻时，各时点费用关于g凸；当p⁺<p⁻时，这个局部几何条件不成立。价格为负不自动意味着非凸，关键是左右斜率关系。不能为了使用某候选而自动裁掉全部负价格。

对递增边际阶梯，若0=v₀<v₁<…、r₁≤r₂≤…，可写

\[
T(Q)=r_1Q+\sum_{j=1}^{J-1}(r_{j+1}-r_j)(Q-v_j)_+,
\quad Q\ge0.
\]

其凸性来自非负折点系数。递减边际阶梯不满足此条件；整段重定价或固定分档费用还可能不连续。必须为每个构造重新分类，不能把“阶梯”统称为凸分段线性。

### 5.2 需量费用与历史

固定窗口平均功率为a_w(g)，令

\[
P_m=\max_{w\in m}a_w(g)_+,
\quad B_D=\kappa P_m,\quad \kappa\ge0.
\]

一个合成ratchet规则可写为B_D=κmax(P_m,ρh_m)，其中h_m为声明的历史基准。历史最高值不一定等同于过去某个账单数值，两者必须具体约定。

top-N规则先得日峰向量d，再取最大N项均值A_N(d)，最后收费F(A_N(d))。top-N求和本身可以是凸算子；F若为分档常数，则会引入跳变。数学难点来自算子组合，而非简单地来自“存在历史”。

### 5.3 电价映射到预测损失

对于固定调度程序T₀、预测z及真实未来y，

\[
\ell_\tau(z,y;s,b)=B_\tau\big(g^{\rm exec}(T_0(s,b,z;\tau),y)\big)+D(u^{\rm exec}).
\]

输出要同时记录纯账单和包含固定设备费用的总成本。以同一可行域的完美未来信息最优值作下界时，所得差额是“相对完美信息后悔”，不等于全部可由更好预测消除的损失。另报相对可实施参考策略的配对成本差。

对于闭式小例、LP/QP证书、枚举整数模式等可核对情况，应保留全局参考；若只有求解上下界，就报告区间。近似求解和不确定最优性不得藏入训练损失比较。

### 5.4 两时段套利锚点

设向电网取电q用于充电，稍后可释放ηq，η=ηcηd，机会成本/退化合计为δq。若释放量用于抵消原本需要购买的电量，则净成本增量为

\[
\Delta C=q(p_L-\eta p_H+\delta).
\]

在容量与负荷余量允许、初末能量一致等条件下，套利方向由m=ηp_H−p_L−δ的符号决定。这是定向采样m<0、m=0、m>0的解析锚点；有需量费或阶梯交互后，应计算完整增量，不能继续仅按价差判定。

固定电价的加法平移也不普遍保持最优策略，因为储能损耗会使不同策略总购电量不同。只在精确说明守恒和目标条件后才可作为等价变换。

## 6．组合空间、语义规范化与目标分布

令a为电价原子选项，h为连接顺序/窗口结构，θ为价格、阈值等参数，b₀为初始计费历史。电价实例为

\[
\tau=\operatorname{Compile}(a,h,\theta,b_0).
\]

设备上下文固定；负荷场景作为共同外生实验输入单独抽样。电价构造不允许偷偷修改电池容量、调度时域或补救规则。

### 6.1 三种有效性不能合并

V-sem：类型、单位、窗口、初态和结算定义完整，程序有确定意义。

V-solve：当前声明问题能否获得可行解、界或证书。

V-behavior：在所选负荷与初态下是否触发了预期计价/决策行为。

只有V-sem失败的实例应从语义支持集剔除。求解器失败应记执行状态；不活跃规则应保留为低激励/负控制实例，不能一律丢弃，否则会人为夸大预测价值。

### 6.2 同一电价可能有多种语法写法

无效选项要投影掉：阶梯关闭时，其阈值变量不得制造许多重复的“不同电价”；最低账单关闭时，其数值和作用域也应停用。相同价位的相邻时段可按已证明的规则合并，但不要任意重排有日历意义的时段。

语法规范化不等于解决任意程序的语义等价判定。只声明支持的重写规则；未知等价保持未知。

若一个电价有10种编码，另一个只有1种，对编码均匀抽样会产生10∶1偏差。采用SAT辅助变量时，采样目标应是决定电价的语义变量投影，而非全部求解变量。UniGen文档提供投影/采样集合接口，具体编码仍需验证。[^5]

### 6.3 指定目标分布p，区分生成分布q

建议主报告使用一个明确的结构分层分布：先按预先给定权重选择电量模式、计量方式等主层，再在该层的规范化合法结构内抽样，随后按条件参数分布取θ与b₀。不要称其为现实电价出现频率。

\[
p(\tau)=p(c)\,p(a,h\mid c,V_{sem})\,p(\theta,b_0\mid a,h,c).
\]

层级均匀还需要考虑“剩余合法补全数”。若前缀为h，候选下一步为v，令N(hv)为相应合法完整结构数，则要得到完整结构均匀分布，应按N(hv)/N(h)选择下一步，而非把当前所有合法分支等概率选择。小空间可精确计数；大空间可以采用带误差管理的近似计数或明确改用另一目标分布。

修复样本也会改变概率。例如两个二元选项(a,b)要求a⇒b，均匀原始编码中合法结构为00、01、11。若把非法10修复为11，最后概率为1/4、1/4、1/2；拒绝10后重采则为各1/3。因此默认不静默修复；确需修复时记录映射及其诱导分布。

规则数量均匀、每条规则独立开启、所有合法结构均匀、所有语法树均匀，均是不同分布。若独立以1/2开启m个可选原子，组合规模服从Binomial(m,1/2)，中等规模自然更多；这不是实现错误，但不能叫复杂度均衡。

如果先采结构再对参数做拒绝筛选，并为每个结构坚持取得固定数量的有效参数，所得到的是条件分布；如果失败便连结构一起重采，则结构权重还会受参数接受率影响。方案应选择其中一种并记录失败，不在运行中随意切换。

| 编号 | 方法 | 可以保证或核查什么 | 局限与用途 |
|---|---|---|---|
| S-U | 小空间精确枚举后抽样 | 明确有限支持上的精确概率 | 空间扩大后内存与枚举成本上升；是可用的校准参照 |
| S-R | 独立提案＋拒绝 | 在正确接受规则下得到相应条件分布 | 接受率可能极低；不能暗中修复样本后仍称原分布 |
| S-H | 分层/层级条件采样 | 明确主层配额与条件分布 | 均匀选局部合法分支通常不等于全局均匀 |
| S-SAT | 近均匀或加权受约束采样 | 在算法假设下控制采样分布 | 需要编码、投影、精度与失败概率管理 |
| S-C | 受约束覆盖数组/集合覆盖 | 有效t元交互与指定高阶交互覆盖 | 不是概率样本，不能直接估计目标总体均值 |
| S-B | 边界与分歧定向搜索 | 提高特定行为触发与反例发现机会 | 带选择偏差，主要用于探索 |

受约束采样有基于通用哈希和SAT求解的理论工作；加权方案还需要检查权重范围等适用条件。[^6][^8] 普通SAT求解器换随机种子并不因此成为均匀采样器。CMSGen官方说明也明确区分uniform-like经验效果与分布保证，因此不能与UniGen的保证混写。[^9]

ACTS支持约束、混合覆盖强度和在已有测试集上扩充，可借鉴其目标定义。[^4] 本轮小空间也可以直接枚举有效交互并做贪心集合覆盖，省去不必要的工具依赖。无论采用哪个实现，都要重新计算实际覆盖，不能把“工具成功退出”当成覆盖证据。

连续参数可采用伪随机抽样或打乱Sobol设计。后者适合空间填充，其2的幂次点数和平衡性质需要遵守官方说明；拒绝、删点和改变坐标依赖会影响原有性质。[^10] 精确边界需单独构造，不能期待连续随机采样命中零测度的平局集合。

本轮对所有适用采样器给出相同预算下的结果，不预设S-H或S-C必胜。组合协议可以最后采用多种采样器分工，但须由有效率、覆盖增量、统计精度和计算成本共同支持。

## 8．参数采样与行为触发

### 8.1 参数尺度

为了避免任意货币尺度主导结果，设p₀>0为参考电量单价，E₀与P₀为固定设备/场景能量和功率尺度。记录价差/p₀、阶梯阈值/E₀、需量费相对p₀E₀的作用量、最低账单/(p₀E₀)等无量纲参数。

可运行的初始探索设置建议：正价格面板以p₀归一化，分时高低价比在[1,4]内取样；折价出口系数在[0,1]内取样；需量与最低账单强度覆盖零、明显不活跃、近临界和明显活跃层。具体数值是合成设计，不是现实费率推荐。负价格为单独面板，直接对有符号价格采样，避免用跨零价格比。

阈值位置可以依据独立校准负荷的累计量、峰值分布构造；不得依据隐藏确认集或候选优劣反复调阈值。各方法共享相同参数实例。

### 8.2 需要触发的行为

| 行为 | 生成控制量 | 核对输出 |
|---|---|---|
| 套利开启/关闭 | m=ηpH−pL−δ | 两侧动作、精确平局 |
| 电量阶梯跨越 | 距累计阈值距离 | 实际落入的阶梯和边际费 |
| 需量峰值切换 | 两个候选峰值差 | 窗口身份变化及费用 |
| ratchet主导切换 | 当前峰值与历史基准差 | 新峰是否增加费用 |
| top-N集合变化 | 第N与第N+1日峰差 | 历史排序和替换事件 |
| 分档收费跳变 | top-N均值距档位阈值 | 边界归属和完整费用跳变 |
| 最低账单掩蔽 | 小计与最低账单差 | 账单敏感区与平台区 |
| 购售切换 | 净交换过零 | 买卖方向和费率 |
| 跨周期变化 | 接近重置、失效与清算日 | 状态继承与清算一致性 |

先使用解析锚点与与候选无关的固定参考策略触发结构，再允许用候选分歧做探索搜索。前者减少生成器围绕某候选定制世界的风险；后者用于发现新失败，但结果单独标注。

所有边界距离要有单位和数值容差。低于求解误差的动作差异只能标为未确定，不能算作已识别机制。

## 9．小型组合空间的已执行核对

为检查“组合采样能否形成具体面板”，构造了下述离散骨架。它是支持范围有限的合成示例，不是完整已知费率库。

| 索引 | 因素 | 编码 |
|---|---|---|
| 0 | 电量时间价 | 0固定；1分时 |
| 1 | 电量阶梯 | 0无；1递增；2递减 |
| 2 | 出口补偿 | 0零；1折价；2同价 |
| 3 | 能量计量 | 0逐时进出口；1窗口净额 |
| 4 | 需量计费 | 0无；1最大值；2历史基准；3 top-N分档 |
| 5 | 最低账单 | 0无；1有 |

此示例暂只定义“窗口净额且无电量阶梯”的语义，故支持条件为x₃=0或x₁=0。被排除的净额阶梯组合属于尚未定义，不是现实非法。分时净额只在同价归属窗口内抵扣；出口补偿不更改物理并网条件；历史数据作为对应规则的必需参数。

实际穷举结果：288种原始编码，192种支持结构；有效二元赋值共103项。另指定三组高阶交互(0,1,3)、(2,3,5)、(0,4,5)，有效三元赋值共36项。采用确定性贪心集合覆盖，用17个结构覆盖了全部139项声明义务，剩余缺口为0。

这一结果仅证明离散标签层面的覆盖构造可行。不证明17个结构最少，不证明192种电价的行为都被覆盖，也不证明候选训练只需17次。每个结构仍要实例化价格、阈值、日历、计费历史和负荷，进行行为核对。

可复现脚本见附录A；没有调用或测试ACTS、UniGen等外部实现。因此本结果不能作为这些工具的性能比较。

## 10．实验方案：生成器与损失两条比较线

### 10.1 实验矩阵

| 实验 | 操作与固定项 | 主要证据 | 完成/停止条件 |
|---|---|---|---|
| E00 已知规则目录 | 从已有资料逐条提取电价语义；设备固定 | 出处—原子—组合—实现对应表 | 每条已恢复规则标明精确、近似、未支持或未核查；不要求先穷尽历史材料 |
| E01 计费解析核对 | 同一功率轨迹用独立公式与编译程序结算 | 阶梯、窗口、最低账单、历史反例 | 所有已支持原子及关键顺序反例通过；不确定状态阻止该实例进入科学比较 |
| E02 采样器校准 | 在可枚举小空间比较S-U/R/H/SAT；目标分布固定 | 有效率、频率偏差、成本、失败与重复 | 有界样本下报告偏差及不确定性；不把一次检验未拒绝当分布证明 |
| E03 覆盖效率 | 比较随机、覆盖设计、边界补样及其组合 | 每单位成本的有效交互、行为新增量 | 达到声明覆盖目标或预算；残留缺口明确 |
| E04 直接预测扰动 | T₀、物理、真实轨迹固定；所有候选同扰动集 | 损失排序、方向、动作与真实费用变化 | 支持条件、反例和未判定区域可定位 |
| E05 小模型训练 | 同数据、输入、输出容量、T₀；换损失 | 配对真实成本、账单分项、资源 | 预注册精度或预算；不能区分则保留未知 |
| E06 组合交互 | 成对启闭电价项，仅在四种组合都有定义时比较 | 差分中的差分与轨迹解释 | 判断规则交互是否解释失真；不能仅凭交互项显著就宣称唯一原因 |
| E07 独立确认 | 冻结候选和采样协议，使用未参与修改的样本 | 同结构新样本、新参数区间、新组合三种结果 | 单独报告三种泛化，不混成总分 |

E00–E03是共同语义和生成证据；E04–E07是损失科学证据。不同规则支线与方法支线可并行，不需要先实现某个损失当主角。

### 10.2 候选登记与适用范围

候选登记至少包括：公式或更新算子、所需规则访问、预测输出类型、理论假设、求解器访问次数、平滑/正则参数、支持的计费几何和信息条件。传统预测损失也按同一标准作为控制组；直接决策目标不预先认定最好。

已有SPO、可微凸层以及PyEPO/PredOpt实现可作为候选来源。不同方法处理目标、约束和非光滑性的范围不同，不能为凑齐矩阵而暗中更换世界。[^11][^12][^13] 无显式标量代理损失的反向更新方法，在E04比较更新方向及真实成本，而不虚构其代理值。

构造不适用、实现缺陷、求解超时、数值精度不足、代理失真和训练失败分别报告。由于某候选未完成而删除整个困难世界，会产生选择偏差；应保留适用矩阵及共同可比较子集。

### 10.3 日历与规划时域

短锚点可用两到四个时段手算。完整运行按声明的实际结算周期生成轨迹，控制网格可为5分钟；需量窗口另行定义为相容的整数步窗口。

主闭环T₀可采用固定24小时滚动规划，但月度费用必须继承累计状态，且对规划窗外的费用采用所有候选一致的尾部近似。该近似本身是共同限制，不能称已求得整月最优调度。另设小规模完整结算周期的精确规划锚点，检查短时域偏差是否支配结果。

如果将一个合成“月”缩短为几天，必须显式命名合成周期；不可拿缩短后的需量费用直接当真实月度费用。

### 10.4 规则交互估计

设A、B为两个可切换规则，d(τ)是某候选相对固定对照的配对成本差。四个世界保持参数对应、负荷和初态一致，定义

\[
I_{AB}=d(\tau_{AB})-d(\tau_A)-d(\tau_B)+d(\tau_\varnothing).
\]

I反映所定义开关与参数下的交互，不是全局因果定理。如果某组合没有合法语义或必须改变另一个关键因素，则不计算这个四项对比，改为明确的条件比较。

特别值得检查的三组交互是：分时价×需量费、净额计量×出口补偿、阶梯/分档×最低账单。它们可能让单项正确的局部损失在组合后失效。

## 11．数据生成、重复量与统计判据

### 11.1 外生数据与配对单位

主轨道将净负荷生成机制固定为公开、可重建且支持有界的合成过程；例如有限状态切换加有界噪声，具有日周期与相关性。先在校准集固定参数和噪声强度，再冻结训练、验证和确认分割。跨电价候选复用同一条基础负荷轨迹。

“同一随机种子”不一定产生可比较随机路径：若执行分支改变随机调用次数，应预先生成外生噪声表。真实闭环状态仍按各候选动作各自演化，不能强制共享储能状态轨迹。

推断单位是独立电价实例×独立完整结算轨迹，必要时包含独立训练种子。单条轨迹中的5分钟点不是独立重复。训练种子重复与世界采样重复分层报告。

### 11.2 三套面板，避免适应性偏差

P-target：按冻结目标分布p抽样，用于估计平均真实成本差。

P-cover：为补足离散交互和行为覆盖生成，不宣称概率代表性。

P-challenge：针对边界或候选分歧搜索，用于发现反例。

覆盖和挑战结果不能直接混入P-target平均值。若确有必要用已知q样本估计p下指标，需要支持包含关系p≪q和可计算概率比。对独立同分布q样本，可用

\[
\widehat\mu=\frac1n\sum_i\frac{p(\tau_i)}{q(\tau_i)}d(\tau_i).
\]

连续参数应使用密度比；层级随机变量与轨迹条件分布也须一致。贪心覆盖设计或未知概率的agent搜索一般不满足直接套用条件。自归一化权重也不自动无偏。最稳妥的主方案仍是另采P-target。

### 11.3 重复量与95%证据标准

不预定“跑五次”或人为设置最低收益阈值。预注册主要成本差及95%区间；只有区间支持改善方向时才声称有改善证据。区间跨零表示未能区分，不能称等价。

试验前用独立小型pilot估计方差与每次计算成本，据目标区间宽度和总预算选确认规模。精度目标是测量要求，不是最低改善门槛。多候选主比较采用预先指定的多重比较控制，探索性分组另外标记。

若必须边运行边查看并停止，使用有条件保证的置信序列或预定批次的显著性分配，不重复使用普通95%区间直到看到想要的符号。相关理论已有成熟文献，但要求独立性/鞅、尾部或有界条件满足。[^14] 主确认实验优先采用冻结样本量，避免把统计方法本身扩为另一个大课题。

规则库扩充后，目标分布也可能变化。旧结果继续属于旧版本总体，不能因新增一个规则便不加说明地合并成同一个均值。

## 12．可操作的成本预算与增样规则

统一记录生成耗时、合法性检查耗时、独立结算耗时、参考求解调用和耗时、候选训练耗时及内存。相同候选训练迭代次数不代表相同预算。

令M为候选数、N为电价参数实例数、R为每实例轨迹数、S为训练重复数。训练成本大致随M×N×S增长，但每次求解成本会随规则结构改变，需实测估计而非只数运行次数。所有方法共享的轨迹和参考解可以复用，仍须分别报告公共建设成本。

建议按以下事实增样：

| 发现 | 下一步 |
|---|---|
| 有效交互未覆盖 | 增加能填补该义务的合法结构 |
| 标签覆盖但行为未触发 | 在同结构内调整阈值/价格，记录定向来源 |
| 平均差不确定 | 按目标分布增加独立轨迹或世界，而非只增加最有利情形 |
| 训练方差主导 | 增加训练种子或检查优化稳定性 |
| 参考求解误差主导 | 改进证书、缩小锚点或报告界，暂不扩大训练 |
| 新规则组合无明确语义 | 建立待定义支线，不自动修复为另一电价 |

停止条件包括：声明的组合覆盖义务完成；主要估计达到预定精度；或预算耗尽并明确残留未知。不得以“当前领先方法胜出”为生成器停止的唯一依据。

## 13．agent协作、TS实验卡与验收

### 13.1 可并行分工

规则解析支线负责来源和数学表达；采样支线负责合法空间和覆盖；候选支线负责损失构造及适配；核对支线负责独立结算、最小反例和统计报告。共享数学契约，不共享未经验证的“通过”结论。

人类介入的重点是规则语义存在多解、现实信息来源不明确、以及证据是否足以支持推广。常规生成、编译、求解与记录可自主执行。开发agent知道规则不等于被测预测器泄漏，但开发过程反复利用隐藏确认结果会污染评估；并行agent也不天然提供信息隔离。

### 13.2 最小实验卡字段

| 字段组 | 必需内容 |
|---|---|
| 身份 | 规则库版本、规范化电价声明、来源、实验轨道 |
| 物理上下文 | 设备、并网、互斥、初末状态、固定设备费用引用 |
| 电价结构 | 原子选项、连接顺序、计量/结算窗口、阈值归属 |
| 信息 | 价格公布时间、负荷观测、计费历史初态 |
| 采样 | sampler标识、种子、目标层、p/q或“不可计算”、拒绝原因 |
| 证据 | 语义检查、计费锚点、求解状态、容差与最优性界 |
| 覆盖 | 应覆盖交互、实际交互、行为触发与未触发原因 |
| 比较 | 候选版本、适用性、训练预算、轨迹与分项费用 |
| 使用身份 | 校准、探索、覆盖、挑战或确认；是否已被开发者查看 |

TS层建议只声明这些输入、依赖和运行计划；数值后端负责解析计费与求解。不要为本次研究再建立庞大的通用世界对象继承体系。常数、阈值和日期变更必须进入计算身份；文字解释变化则保留理论版本关系。

### 13.3 必须通过的验收条件

A1：组合的单位、窗口、作用对象和初始计费历史完整；未知不算有效。

A2：第3节四个顺序/计量反例，以及每个启用原子的独立计费核对通过。

A3：简化骨架的192个支持结构及139项目标交互可重建；扩充语法后重新计算分母。

A4：每个标为“行为覆盖”的事件存在轨迹证据；标签出现不能代替行为证据。

A5：候选之间没有隐藏的设备、信息、调度或补救差异；例外作为独立候选。

A6：P-target、P-cover、P-challenge分开；确认样本没有被用于调整本轮候选。

A7：参考求解失败、超时、未知最优性与未完成训练不能被汇总为科学通过。

A8：报告包括适用矩阵、原始账单、设备费用、配对差与区间、资源成本和未支持规则。

## 附录A：离散骨架覆盖的可复现代码

以下Python代码仅实现第9节的标签枚举与贪心覆盖，不是电价结算器或储能求解器。只有一个局部支持约束，尚未替代完整规则语义检查。贪心顺序固定，不主张全局最小覆盖集。

```python
from itertools import product, combinations

# 时间价、阶梯、出口补偿、计量、需量、最低账单
raw = list(product(range(2), range(3), range(3),
                   range(2), range(4), range(2)))
valid = [x for x in raw if x[3] == 0 or x[1] == 0]
pairs = list(combinations(range(6), 2))
triples = [(0, 1, 3), (2, 3, 5), (0, 4, 5)]

def obligations(x, groups):
    return {(g, tuple(x[i] for i in g)) for g in groups}

universe = set().union(*(obligations(x, pairs + triples) for x in valid))
missing = universe.copy()
selected = []
while missing:
    x = max(valid, key=lambda row:
            len(obligations(row, pairs + triples) & missing))
    gain = obligations(x, pairs + triples) & missing
    assert gain
    selected.append(x)
    missing -= gain

assert len(raw) == 288
assert len(valid) == 192
assert len(universe) == 139
assert len(selected) == 17
assert not missing
print(selected)
```
