# Agent Engineering Science 后续研究：独立学术审查

2026-09-24。审查对象：用户提供的《我按“原报告之后的下一层问题”继续追了……》全文。审查类型：理论、数值及文献核对；不是对所有原始实验的逐条代码复现。

## 总体裁决

**建议：重大修改后作为研究纲领发表；暂不作为已确立的工程定律或经实证辨识的统一理论。** 核心洞见“收到信息不等于正确整合信息”有实证依据，分解为生成、传递、整合、验证、决策有很强的研究价值。但是，论文间任务和输出准则不同；所提七条关系中有可构造的严格反例；自述 Monte Carlo 未说明相关联合分布；所建议的 2×2×2 实验缺少欲求导的 N 维度。因此目前最高可信表述是“机制假设＋可证伪的实验纲领”，而不是“普适律”。

### SILO 中需要独立识别的因果链

论文中的“Communication–Reasoning Gap”足以提出问题，但通信密度只是消息量代理，不是“传递成功”或“正确理解”的观测。理想的分层诊断至少记录：原始私有 shard 是否包含答案所需证据；信息是否被发送；接收方是否可检索；是否正确解释；聚合决策是否正确；全员输出约束是否满足。将相同冻结消息交给多个预注册聚合器，才可能在固定信息的条件下比较整合算法。带答案的 oracle 聚合器只能提供诊断上界，不能与同预算生产系统当成公平比较。

“通信复杂度”应给出消息数或 bit 数、最大消息大小、回合数、输入分配、允许误差、输出位置及协议限制；否则 C_T 与所谓 C_A 并不处于相同量纲，也谈不上一个可检验的临界点。SILO 的全员输出评分还需要与单节点输出或仅各节点局部输出分别比较。其 1,620 是任务×配置的实验总数，不等同于同一配置上 1,620 次独立重复。

## 自述相关投票实验的可复核性

原文给 p=0.7、ρ∈{0,.3,.7,.9}、N∈{5,17,33}、每格 30,000 次，却未给出相关 Bernoulli 联合分布的生成方法、随机种子、置信区间、原始样本或脚本。因此表格不可从附件独立复现。关键不是实现细节：只指定 p 与成对 ρ，仅固定了一阶和二阶矩，多数票依赖更高阶联合结构。

可复算的一个对照是假设潜在准确率 Θ∼Beta(a,b)，条件于 Θ 各 Agent 独立 Bernoulli(Θ)，其中 a=p(1/ρ−1)，b=(1−p)(1/ρ−1)。这与文中完全具有相同 p 和两两相关 ρ，且 N_eff=N/[1+(N−1)ρ] 不变。此时精确多数票概率为 Σ_{k> N/2} Binomial(N,k) B(k+a,N−k+b)/B(a,b)。

| N | ρ | 原文 Monte Carlo | 上述相同一、二阶矩模型的精确概率 |
|---:|---:|---:|---:|
| 5 | 0 | .838 | .836920 |
| 33 | 0 | .992 | .992179 |
| 5 | .3 | .773 | .744250 |
| 33 | .3 | .820 | .767641 |
| 5 | .7 | .723 | .705736 |
| 33 | .7 | .732 | .707613 |
| 33 | .9 | .708 | .700716 |

这里不是断言原表错误；原表可能采用高斯阈值、common shock 或其他相关生成器。恰恰因为这些都与 p、ρ 兼容，不说明联合生成机制，就无法由表格推出“只用 N_eff 就足以描述 scaling”。例如 ρ=.3、N=33 时，相同 N_eff≈3.113 的两种机制已经在多数票上相差约 5.2 个百分点，显著超过每格 30,000 次 Bernoulli 采样带来的量级约 0.25 个百分点的标准误。后一个比较是不同理论模型的差异，并非对原模拟的统计检验。

N_eff 恰是等相关样本均值方差的等效样本数，因为 Var(Ȳ)=p(1−p)[1+(N−1)ρ]/N；它并不决定多数票胜率、尾部风险或整合效率。可保留为方差尺度的协变量，不宜将 Gain∝N_eff 写成定律。

## 七条候选“定律”的数学审查

| 假说 | 判断与可接受版本 |
|---|---|
| L1 有效多样性 | **当前形式不成立。** 等相关同方差也有不同多数票成功率；增益并非一般地正比 N_eff。限定为等相关均值估计的方差恒等式，或在明确联合分布与融合器之后估计响应曲线。 |
| L2 整合瓶颈 | **负边际价值不是一般结论。** 若新观测可以零成本忽略且策略集合包含旧策略，最优期望收益满足 V(O,new)≥V(O)。更多观测降低净价值需要强制摄入、处理成本、有限上下文置换或策略能力限制。可将信息到达率、可验证处理率及积压 Q_{t+1}=[Q_t+A_t−S_t]^+ 作为队列假说；积压增长本身不推出任务效用下降。 |
| L3 协调复杂度 | **尚未可操作化。** C_T 和 C_A 必须同单位、同任务边界、同错误准则；若 C_A 事后定义为“系统可解的问题上界”，断言变为同义反复。要求独立任务复杂度代理和先验测得的系统容量，再进行留出任务外推。 |
| L4 上下文投影 | **表达式没有定义。** RawHistory 包含任何由它计算的摘要，在无限计算与无代价情形下不能被摘要的信息优势支配。有限窗口或计算成本下，可比较给定预算的最小决策后悔和编码开销。 |
| L5 验证耦合 | **方向有意义，公式不具约束力。** “Value=f(VerifierQuality)”总可以成立，不能证伪；预先规定生成数量、验证的假阳性/假阴性率、费用及交互效应，考察是否优于等预算独立采样。 |
| L6 认识反馈 | **有现实动机，无动态律。** ρ_{t+1}=f(ρ_t,G,C,EvidencePolicy) 未给 f 的形式与观测定义。线性共识模型 b(t+1)=[(1−α)I+αW]b(t) 在适当连通/非周期条件下趋于共识，但共识可能是错的；含持续不同证据时一般也未必完全共识。 |
| L7 有限最优计算 | **需要明确成本与目标。** 若准确收益有界且每一步至少支付 c>0 并计入效用，则整数计算步数的净效用在某个有限步最大；若 B 只是可用预算，V(B)=sup_{cost≤B}E[reward] 可单调上升且仅渐近逼近上界，不保证有限 B*。 |

“Decision-Sufficient State”的更严谨研究定义：给定任务分布、可执行策略类 Π、预算 B、历史 H 和编码器 φ_B，令 R_B(φ)=inf_{π∈Π(φ(H)),cost≤B}E[L(π)]；相对同预算历史可用策略的 excess regret Δ_B(φ)=R_B(φ)−R_B(identity)。在编码器、解码器和检索成本全部入账的前提下，考察编码长度/内存占用 c(φ) 与 Δ_B 的 Pareto 前沿。原式 min |S| subject to Regret≤ε，若不约束状态精度、编码长度和未来任务，可把整段有限历史无损塞入单个无限精度实数而使 |S|=1；一次动作的最优同值也不保证未来交互的充分性。真正的动态状态还需对未来观测、可选动作和回报作预测充分性约束。

“IntegrationEfficiency”建议先作**任务条件诊断指标**而非标量本体：固定任务、证据包、消息、预算和解码测试，报告可用证据召回、信息理解率、正确联合运算率、验证纠错率的分层转移概率；用同证据同预算的聚合算法随机分配估计因果改善。跨任务归一化若需引入 oracle 分母，须声明 oracle 是上界，并排除 oracle 与基线收益相等或分母近零的格子。

## 下轮实验的最小可识别设计

原文 2×2×2 是相关性×整合×验证，却要求估计 ∂J/∂N；因为没有 N 因子，这一导数**统计上不可识别**。建议用 N∈{2,5,10,20} × 来源相关低/高 × 固定消息后的聚合器弱/强 × 验证关/开；单 Agent 单独作参考。严格冻结任务、知识 shard 分配和模型版本；共同外生冲击调节错误相关性，同时保持个体准确率近似恒定；对聚合器与验证器进行独立随机化。相关性是源输出的结果而非天然随机处理变量，应同时报告实际测得的 ρ 和所施加干预。

每个任务实例在各处理格做配对比较，多随机种子，按任务聚类并报告模型×任务×协议异质性。成功率之外，记录每一步证据获取、送达、理解、融合与纠错状态，token、工具调用、墙钟、钱和输出位置。预注册主检验：在给定成本与任务族内，强聚合器相对于弱聚合器是否使 N 增加时的边际净收益更高（N×聚合器交互）；检验 N×相关性、N×验证及四因子交互，控制多重检验并对留出模型/任务检验迁移。不给“只有三者全强才有正斜率”的必要性结论，因为即使没有显式验证器，独立候选与精确多数融合也能受益。

明确的反证样本：给已经完备的融合器注入重复消息；保持消息数量而改变证据价值；允许代理忽略新消息；更改“全员答案”与“单出口答案”；用非 IID 故障取代等相关源；让 verification 偶尔错误。若控制这些条件后现象消失，便应将规律定位为协议与资源限制之下的局部经验规律。

## 推荐修订标题与学术定位

建议标题：**《分布式 Agent 的信息整合瓶颈：证据审查、不可识别性与系统辨识实验纲领》**。开篇把七条称为“带限定条件的可证伪命题”，单列“已证明的数学事实”“实测关联”“机制解释”“新假设”；公布 Monte Carlo 生成器、种子、置信区间与成本口径。跨基准结果只能充当机制相容的三角证据，不能写作同一潜在变量的交叉验证。最佳贡献点是提出可操作的分层机制诊断和跨模型的留出预测，而不是给尚未估计的 C_A 或 η_I 命名。
